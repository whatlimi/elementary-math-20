## 这是什么

`guizang-demo` 是**个人工作区**，不是一个单一软件项目。里面放了一组彼此独立的
单文件 HTML 工具（双击即开，无构建链），外加若干历史原型和备份。核心活跃项目
只有一个：`math-20.html`（数学乐园）。

## 能跑吗（baseline）

- 全部为静态 HTML/JS，无 build/test/lint 管线。
- `math-20.html`：语法检查用 `node` 包裹 script 块 `new Function()` 校验通过；
  交互逻辑曾用轻量 DOM mock 断言验证过（历史会话），当前无留存的自动化测试脚本。
- 其余工具（notion-library / zentao-tool / r2d-agent / multi-model-consult）交付时
  各做过一次性断言验证，无自动化测试留存。
