# song-english-vocab — 听歌悟单词（45 首英文歌记完高中 3500 词）

> 需求文档（what + why）。对应设计见 [design/song-english-vocab.md](../design/song-english-vocab.md)。

## 是什么

以「听 45 首英文歌」为载体记忆高中英语 3500 词的工具/内容清单。
书的出处：汉知简《45首英文歌记完高中3500词》（ISBN 9787830127220，山东电子音像出版社）。
网上流传同名歌单已找到（见 [song-playlist.md](../../docs/song-playlist.md)），45 首全齐。

## 谁在用 / 为什么做

- 场景：高中生（或有高中词汇需求的学习者）通过英文歌的旋律、节奏和语境记单词，替代死记硬背。
- 痛点：3500 词孤立背诵枯燥、易忘；听歌可利用节奏记忆锚点 + 语境记忆。

## 核心需求（用户已澄清）

1. **45 首歌的歌单清单**：歌手 + 歌名 + 分类 + 学习要点，供人工确认。→ 已完成
   （`docs/song-playlist.md`）。
2. **每首歌对应词表**：从每首歌的歌词文本中自动提取属于高中 3500 词表的词（用户已拍板此方案）。
   要求可溯源、词确实出现在歌词里。
3. 后续（确认歌单后）：单文件 HTML 学习应用（歌词逐句高亮、生词点击查义等）。

## 数据来源与工具

- **词库**：`docs/wordlist/GaoKao_3500.json`（qwerty-learner 开源项目的 GaoKao_3500 词表，
  3893 词，含音标 + 中文释义）。下载自 jsdelivr CDN（沙箱内可直达）。
- **歌词**：LRCLIB 开放 API（lrclib.net）。脚本 `scripts/fetch-lyrics.mjs` 逐首抓取
  45 首歌词存入 `docs/lyrics/<id>.json`。⚠ 沙箱内直连被拦，需用户在本机跑一次脚本
  （网络正常的机器可直达）。
- **提取脚本**：`scripts/extract-vocab.mjs`（待写），本地比对歌词 token 与词库，
  产出每首歌的 3500 词命中表。

## 非目标（明确不做）

- 不做原书电子版复制 / 盗版内容库。
- 歌单确认前不做应用。

## 关键行为约定（用户拍板，勿回退）

- 歌单出处以书为准，歌曲、歌手名不擅自改。
- 词表必须标注来源（歌词提取），不凭空编造。
- 4500 词命中提取：只比对「原形词」（歌词 token 去屈折后匹配词库 name）。
